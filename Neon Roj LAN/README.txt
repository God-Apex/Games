NEON ROJ - co-op v síti (LAN)

Spuštění
1. Na jednom počítači dvakrát klikni na "Spustit co-op server.bat"
   (nebo v terminálu: python server.py). Stačí Python 3.8 nebo novější.
2. Otevře se prohlížeč s hrou. V menu zvol "Co-op v síti".
3. Ostatní ve stejné síti otevřou adresu, kterou server vypíše
   (např. http://192.168.1.23:8090), a taky zvolí "Co-op v síti".
4. Až budou všichni připravení, hostitel (kdo se připojil první) spustí let.

Když se ostatní nemůžou připojit
- Windows se při prvním spuštění zeptá, jestli povolit Python v síti.
  Povol "Soukromé sítě".
- Všichni musí být ve stejné síti (stejná Wi-Fi nebo kabel).
- Obsazený port: python server.py 8091

Hra
- 2 až 4 hráči, společný roj a společné úrovně.
  Každý si vybírá vlastní vylepšení a sbírá vlastní truhly.
- Sestřeleného spoluhráče oživíš, když k němu přiletíš a chvíli u něj zůstaneš.
- Úlomky, úspěchy a lodě se ukládají každému v jeho prohlížeči.
- Hra pro jednoho hráče funguje i tady, stačí v menu zvolit Hrát.
